# BG Studio 3D V3.1.75

## Site İçerik Merkezi + Çerez Tercihleri + Hero Clip Fix

Baz: V3.1.74 Project / Case Study Manager

### Site İçerik Merkezi
- Product Manager'a `Site İçerikleri` yönetim düğmesi eklendi.
- Ana Sayfa, Kurumsal, Prototip / Parça, Hakkımızda ve İletişim hero içerikleri panelden yönetilebilir.
- Başlık, açıklama, üst etiket ve CTA metin / bağlantıları kalıcı AppData koleksiyonundan gelir.
- Ana sayfanın büyük hero ürünü ve sağdaki iki ürün görseli katalogdaki aktif ürünlerden seçilebilir.
- Hero ürün seçimi boş bırakılırsa mevcut öne çıkan / aktif ürün otomatiği korunur.
- Boş veya geçersiz alanlar mevcut güvenli varsayılana döner.
- `javascript:` / `data:` gibi güvenli olmayan CTA protokolleri kabul edilmez.
- Kayıt sonrası site otomatik yeniden oluşturulur.

### Çerez tercihleri
- Global footer'a görünür `Çerez tercihleri` düğmesi eklendi.
- Yasal sayfalara eksik olan `consent.js` yüklemesi eklendi.
- Footer alan tüm public sayfalarda consent script eksikse build sırasında otomatik eklenir.
- Mevcut privacy-first Analytics izin sistemi korunur.

### Ana sayfa hero görsel düzeltmesi
- Hero ürün kartlarındaki yarı saydam beyaz dış border kaldırıldı.
- Hover zoom sırasında oluşan açık renk kenar / clipping parlamasını önlemek için koyu fallback yüzeyi, isolation ve GPU clipping koruması eklendi.
- Hafif zoom animasyonu korunur.
- Büyük kart ve sağdaki iki küçük kart aynı güvenli clipping davranışını kullanır.
