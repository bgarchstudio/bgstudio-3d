# BG Studio 3D V3.1.93

Baz: V3.1.92

## Düzeltme

Ana sayfa ilk yüklenirken birkaç salise görünen eski/büyük ham ürün görseli kaldırıldı.

### Kök neden
V3.1.83 döneminden kalan `data-critical-v3183` ilk-boyama CSS'i eski ana sayfa hero yapısını hedefliyordu. V3.1.91–92 ile hero tamamen Spatial Product Showcase yapısına geçti fakat ana stylesheet hâlâ asenkron yükleniyordu. Tarayıcı tam CSS gelmeden önce yeni hero HTML'ini eski kritik CSS ile çiziyor, bu yüzden ürün görseli kısa süre dev boyutta görünüyordu.

### V3.1.93 çözümü
- Ana sayfada `styles.min.css` ilk boyamadan önce normal/blocking stylesheet olarak yüklenir.
- Ana sayfada eski V3.1.83 kritik CSS bloğu enjekte edilmez.
- Alt sayfalarda mevcut async CSS + critical CSS performans düzeni korunur.
- Spatial Product Hero, ürün verileri, navbar, NFC, Product Manager ve V3.1.89 WhatsApp düzeltmeleri korunur.
- Asset sürümü `3.1.93` yapıldı; eski tarayıcı önbelleği karışmaz.

## Değişen dosya
- `tools/product_manager/build.py`

## Uygulama
1. V3.1.92 üzerine patch dosyasını kopyala.
2. Product Manager'ı kapatıp yeniden aç.
3. Siteyi yeniden üret.
4. Commit + push yap.
5. Canlı sitede Ctrl+F5 ile ilk yüklemeyi test et.
