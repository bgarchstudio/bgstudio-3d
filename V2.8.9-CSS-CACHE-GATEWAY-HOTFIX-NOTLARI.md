# V2.8.9 CSS Cache / Gateway Hotfix

- Ana sayfadaki yeni BG Studio marka geçidinde logoların dev boyutta görünmesine yol açabilen eski `styles.css` tarayıcı/CDN önbelleği etkisi giderildi.
- Tüm HTML sayfalarındaki ana stil dosyasına `?v=2.8.9` cache-busting parametresi eklendi.
- Ürün yöneticisinin gelecekte üreteceği ürün sayfaları da aynı sürümlü CSS adresini kullanacak şekilde güncellendi.
- Ana sayfadaki üç gateway logosuna, CSS önbelleği tekrar eski bir dosya döndürse bile doğal PNG ölçülerinde taşmayı engelleyen küçük bir boyut güvenlik katmanı eklendi.
- Mevcut V2.8.8 tasarım yapısı, logo dosyaları ve diğer site içerikleri değiştirilmedi.
