# BG Studio 3D v2.8.4 — Kalıcı Yönetici Launcher

Bu sürümde paneli başlatan CMD repo güncellemelerinden ayrıldı.

## Bir kez yapılacak kurulum
1. Repo klasöründe `KALICI-YONETICI-KUR.cmd` çalıştırılır.
2. Sistem `%LOCALAPPDATA%\BGStudio3D\launcher` altında yerel olarak yeni launcher üretir.
3. Repo yolu `repo-path.txt` içine kaydedilir.
4. Masaüstüne `BG Studio 3D Yonetici` kısayolu oluşturulur.

## Bundan sonra
- Yeni ZIP/patch içindeki CMD dosyalarını çalıştırmak gerekmez.
- Panel her zaman masaüstündeki kalıcı kısayoldan açılır.
- Launcher repo içindeki güncel `server.py` ve `storage_cli.py` dosyalarını kullanır.
- Kalıcı ürün/veri kasası yine `%LOCALAPPDATA%\BGStudio3D` altındadır.
- Repo taşınırsa launcher yeni yolu kullanıcıdan ister ve yeniden kaydeder.

## Windows engelinin çözümü
Kalıcı launcher internetten indirilmez; kurulum sırasında bilgisayarda yerel olarak üretilir. Bu nedenle sonraki site güncellemelerinde yeni CMD için tekrar tekrar "Engellemeyi kaldır" yapılması gerekmez.
