# BG Studio 3D V3.3.28 · Google Reviews

Baz: V3.3.27 Gallery Lightbox

## Değişiklikler
- Ana sayfaya "Sahadan Referanslar" bölümünün altına Google yorumları bölümü eklendi.
- Veri Google Places API (New) üzerinden BG Assistant Worker'ın `/api/google-reviews` uç noktasından gelir.
  - API anahtarı yalnız worker secret'ıdır (`GOOGLE_PLACES_API_KEY`); sitede görünmez.
  - Yanıt Cloudflare önbelleğinde 24 saat tutulur; Google'a günde ~1 istek gider. Hata yanıtı 10 dk önbelleklenir.
  - `GOOGLE_PLACE_ID` tanımlı değilse işletme "BG Studio 3D Kuşadası" ile aranır ve adı doğrulanır.
- Bölüm: puan rozeti, en fazla 5 yorum kartı (yazar, yıldız, metin, tarih, Google etiketi),
  "Tüm yorumları Google'da oku" ve "Yorum yaz" bağlantıları. Mobilde kartlar yatay kaydırılır.
- Anahtar yoksa veya Google yanıt vermezse bölüm yalnız Google bağlantılarıyla görünür.
- Yorum metinleri Google'dan kopyalanıp sayfaya yazılmaz; AggregateRating şeması eklenmedi
  (Google kendi sitesindeki işletme yorumları için yıldız göstermez).

## Kurulum (bir kez)
1. Google Cloud'da Places API (New) etkinleştir, API anahtarı oluştur, anahtarı yalnız Places API (New) ile sınırla.
2. `npx wrangler secret put GOOGLE_PLACES_API_KEY --name bgstudio-ai-assistant`

Cloudflare Worker güncellendi (V3.3.28).
