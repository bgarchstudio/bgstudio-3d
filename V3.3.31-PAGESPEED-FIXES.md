# BG Studio 3D V3.3.31 · PageSpeed Fixes

Baz: V3.3.30 Compact Project Index
Kaynak rapor: PageSpeed Insights, 6 Kas 2026 — Mobil 89 / Masaüstü 97, Erişilebilirlik 96.

## Performans
- **LCP render gecikmesi (mobil ~2 sn):** Hero görseli `data-home-motion` kaydırma animasyonuna dahildi;
  `homepage.js` yüklenince hero gizleniyor, IntersectionObserver tetiklenince geri geliyordu.
  Hero öğeleri artık hemen görünür; animasyon yalnız ekran altındaki bölümlerde çalışır.
- **Dock küçük görselleri:** ~58×44 px gösterilen butonlar tam boy ürün görselini (134–218 KB) indiriyordu.
  160 px türev kullanılıyor (3–5 KB).
- **Pillow kuruldu:** `_ensure_responsive_variant` Pillow olmadan türev üretemiyordu; yeni ürünlerde
  -480/-800 görseller oluşmuyordu (ör. 3-bolmeli-gunluk-ilac-kutusu). Derleme artık görsel boyutlarını da
  yazar (boyutsuz görsel sayısı 30 → 0).
- **Zorunlu yeniden düzenleme:** `navigation.js` başlangıçta `scrollY` ve menü ölçülerini senkron okuyordu;
  ilk ölçüm `requestAnimationFrame` içine alındı.
- **WhatsApp nabız animasyonu:** `box-shadow` keyframe'leri GPU'da birleştirilemiyordu; halka `::after`
  katmanında `transform`/`opacity` ile çiziliyor.

## Erişilebilirlik
- Süreç adımlarında pasif adımlar `opacity:.46` ile soluklaştırılıyordu (AA altı). Opaklık kaldırıldı;
  pasif adım yalnız başlık rengiyle ayrışır.
- Çerez paneli `<aside role="dialog">` → `<div role="dialog">` (aside bu rolü alamaz).
- Ana sayfa "Ürünü incele" bağlantılarına ürün adlı `aria-label` eklendi.

## Yapılmayanlar
- **Önbellek süresi (10 dk):** GitHub Pages `Cache-Control: max-age=600` sabit verir; değiştirilemez.
  Daha uzun önbellek için alan adının önüne Cloudflare proxy gerekir.
- **Kullanılmayan CSS (~57 KB):** görsel regresyon referansı olmadan budanmadı.
- **Masaüstü CLS 0,048 (web font değişimi):** "iyi" eşiğinin (0,1) altında; `display=optional` ilk ziyarette
  marka fontlarını gösterememe riski taşıdığı için değiştirilmedi.

Cloudflare Worker değişmedi.
