Baz: V3.3.20-R1

## Canonical bütünlüğü
- Her public HTML için beklenen temiz canonical URL build sırasında hesaplanır.
- `/teklif/index.html` dosyasının canonical hedefi kesin olarak `https://3d.bgstudio.com.tr/teklif/` olur.
- `/index.html` hiçbir canonical veya sitemap URL'sinde kullanılmaz.
- Bir sayfada birden fazla canonical varsa build sonrasında tek canonical'a indirilir.
- Mevcut `og:url` alanı varsa canonical ile eşitlenir.
- 404 canonical hatası `/404.html/` yerine `/404.html` olarak düzeltilir ve 404 `noindex,follow` kalır.

## Sitemap 2.0
Sitemap artık elle tutulan URL listesinden değil, build sonunda oluşan gerçek public sayfalardan üretilir:
- yalnız indexable sayfalar
- yalnız temiz canonical URL'ler
- noindex sayfalar hariç
- duplicate canonical engeli
- ürün ve proje sayfaları otomatik dahil
- yeni public sayfa eklendiğinde sitemap elle güncellenmek zorunda kalmaz

## Robots
Arama motorlarının static deployment içindeki kaynak/config klasörlerini taramaması için:
- `/tools/`
- `/data/`
- `/cloudflare/`
- `/launcher/`
Disallow eklendi. Public site sayfaları Allow olarak kalır.

## /index.html temiz URL
Kullanıcı doğrudan `/teklif/index.html` veya başka bir `/index.html` URL'sine gelirse browser adresi `history.replaceState` ile temiz canonical biçime çevrilir. Bu bir HTTP 301 değildir; SEO'nun ana sinyali canonical + sitemap'tir.

Static hosting katmanında gerçek 301 yönlendirmesi destekleniyorsa ayrıca uygulanabilir. Bu sürüm hosting sağlayıcısı varsayımı yapıp çalışmayan `_redirects` dosyası eklemez.
