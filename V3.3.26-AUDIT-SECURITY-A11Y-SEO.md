Baz: V3.3.25 Mobile SERP Title Hygiene

## Güvenlik
- BG Assistant Worker artık Origin başlığı olmayan veya izinli olmayan istekleri 403 ile reddeder.
- IP başına dakikada 8 istek sınırı (Cloudflare `RATE_LIMITER` binding, yoksa isolate içi yedek sınır).
- Worker `versions upload` + `versions deploy` ile yayınlandı; `ai.bgstudio.com.tr` route'u değiştirilmedi.
- GitHub Pages kaynağı "GitHub Actions" yapıldı. `.github/workflows/pages.yml` yalnız public site dosyalarını yayınlar;
  `tools/`, `launcher/`, `cloudflare/`, `data/` (site_settings.json hariç), build script'leri ve sürüm notları artık 404 döner.

## Erişilebilirlik (WCAG 2.2 AA)
- axe-core ile 4.5:1 altında ölçülen küçük etiketler koyulaştırıldı.
- Öne çıkan NFC paket kartındaki koyu zemin üstü koyu metin düzeltildi.
- Referans marquee kopyası `inert`; NFC akış şeridi klavyeyle odaklanabilir.
- İç içe `<aside>` landmark uyarıları giderildi; hızlı işlem butonları `<aside>` landmark'ı oldu.
- Ürün kataloğuna eksik `<h2>` (ekran okuyucu için) eklendi.
- Mobilde (≤760px) back-to-top gizlendi; sağ altta 2 buton kalır.

## SEO
- Tüm sayfalarda `og:image` (proje detaylarında projenin kendi görseli).
- Hakkımızda, İletişim, Teklif ve Projeler title'ları; Projeler meta description'ı uzatıldı.
- Footer'a Kişiye Özel Ürün Koşulları bağlantısı eklendi.

## Bilerek yapılmayanlar
- Product `shippingDetails` / `hasMerchantReturnPolicy`: kesin kargo ücreti ve iade süresi tanımlanınca eklenmeli.
- Kullanılmayan CSS temizliği: görsel regresyon referansı olmadan yapılmadı (gzip ~62 KB).
