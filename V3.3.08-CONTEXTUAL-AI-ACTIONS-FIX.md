# BG Studio 3D V3.3.08 · Contextual AI Actions Fix

Baz: V3.3.07 Spatial Hero Cleanup

## Kök sorun
OpenAI doğru metni üretse bile mesajın altındaki CTA kartları `localResolve()` fallback sonucundan alınıyordu.
Bu nedenle “Profesyonel paket kaç TL?” gibi bir NFC sorusunda cevap doğruyken altta alakasız bir katalog ürünü çıkabiliyordu.

## Düzeltmeler
- OpenAI cevabı ile CTA yönlendirmesi birbirinden ayrıldı.
- CTA'lar artık kullanıcının gerçek niyetine göre `contextualActions()` ile belirleniyor.
- NFC / QR / restoran / paket / masa sorularında yalnızca:
  - NFC + QR sistemleri
  - NFC teklifi al
  yönlendirmeleri gösterilir.
- Founder sorularında Architecture + BG Studio 3D yönlendirmeleri korunur.
- Özel üretim / prototip / kurumsal sorular kendi doğru sayfalarına gider.
- Ürün kartları yalnızca gerçekten ürün arama / ürün önerisi niyeti olduğunda gösterilir.
- OpenAI geçici olarak devre dışı kalırsa Profesyonel / Başlangıç / Premium / Hızlı Bağlantı paket fiyatları local fallback tarafından da doğru okunabilir.
- OpenAI'nın zaman zaman döndürdüğü `**kalın**` Markdown yıldızları kullanıcıya ham görünmesin diye ekranda temizlenir.
