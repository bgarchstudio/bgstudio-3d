# BG Studio 3D V3.1.85

Baz: V3.1.84 Mobile Viewport Nav Fix

## Düzeltmeler

### 1. NFC + QR mobil referans boşluğu
`Sahada çalışan örnekler` bölümü tüm referans kartlarını saran tek ve uzun `.reveal` kapsayıcısına bağlıydı. Mobil ekranda IntersectionObserver yüzde 12 görünürlük eşiğine ulaşamadığında kapsayıcı `opacity:0` durumunda kalabiliyor, bölüm yüksekliği dururken içerik görünmüyordu.

V3.1.85:
- NFC referans bölümünün ana `shell` kapsayıcısından `reveal` sınıfını kaldırır.
- Eski üretilmiş HTML kalırsa CSS güvenlik kuralı referans kapsayıcısını görünür tutar.
- NFC kart verisi, sırası, tema seçimi ve proje bağlantıları değişmez.

### 2. Masaüstü üst menü açılır grupları
V3.1.83 performans turunda tam CSS asenkron yüklenirken kritik CSS HTML sonunda inline ekleniyordu. Kritik CSS içindeki `.nav-submenu{display:none}` kuralı tam CSS'ten sonra geldiği için masaüstünde `Üretim`, `İşletmeler` ve `BG Studio` alt menülerini kalıcı olarak gizleyebiliyordu. JS `is-open` sınıfını eklese bile `display:none` devam ediyordu.

V3.1.85:
- Kritik ilk boya kuralı `display:none` yerine grid + görünmez durumuna çevrildi.
- Masaüstünde alt menülerin gerçek grid yapısı `display:grid!important` ile güvenceye alındı.
- Hover, tıklama ve klavye focus durumları görünürlük kurallarını açık biçimde geri getirir.
- `navigation.js` init sürümü 3.1.85'e yükseltildi.
