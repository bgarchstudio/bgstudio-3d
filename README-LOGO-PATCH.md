# BG Studio 3D v1.5 Logo + Favicon Patch

Bu paket mevcut `bgstudio-3d` GitHub Desktop klasörünün üzerine kopyalanır.

## Ne değişir?
- Yeni BG Studio 3D favicon seti
- Apple Touch ve PWA ikonları
- Header/footer içindeki BG monogramı yeni metalik logoya geçer
- Site manifest ikonları güncellenir
- Genel sayfaların sosyal paylaşım görseli BG Studio 3D marka görseline geçer
- Ana sayfa LocalBusiness schema içine logo URL'si eklenir

## Uygulama
1. ZIP'i çıkar.
2. `bgstudio3d-v1.5-LOGO-FAVICON-PATCH` klasörünün **içindekileri** GitHub Desktop'ın açtığı `bgstudio-3d` klasörünün üzerine kopyala.
3. Var olan dosyaların değiştirilmesini onayla.
4. GitHub Desktop: Summary `Add BG Studio 3D logo and favicon`
5. Commit to main -> Push origin.

`CNAME` bu patch içinde yoktur; custom domain ayarına dokunmaz.
