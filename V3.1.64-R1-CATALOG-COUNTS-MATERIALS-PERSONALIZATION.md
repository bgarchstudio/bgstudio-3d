# BG Studio 3D V3.1.64-R1

## Catalog counts + Materials + Personalization hotfix

Base: V3.1.64 Premium Product Catalog

### Fixed
- Category product counts no longer visually stick to category names.
- Counts now use a dedicated `filter-count` pill with independent spacing.
- `Kişiselleştirilebilir` is now an explicit Product Manager checkbox.
- Category, title, description, tags, or `Hediye & Kişiye Özel` category no longer automatically make a product personalizable.

### Material system
- Added persistent global material library.
- Defaults: PLA, PLA+, PLA HD, PETG, TPU, ASA, ABS.
- New materials can be added from Product Manager.
- Products can select one or more materials from the library.
- Catalog material filter is driven by explicit product material selections.
- Legacy products without `material_ids` keep text-based material detection until they are edited and saved.
- Empty explicit material selection disables material inference for that product.

### Product Manager implementation
- Existing `manager.js` and `manager.css` are not replaced.
- `server.py` injects a small idempotent companion layer into the existing manager shell.
- New files:
  - `tools/product_manager/static/catalog-admin.js`
  - `tools/product_manager/static/catalog-admin.css`
- New endpoints:
  - `GET /api/materials`
  - `POST /api/materials/save`
- `/api/products` now includes the global material library.

### Persistence / safety
- Product metadata fields: `material_ids`, `personalizable`.
- Existing products preserve these fields even if the companion UI fails to submit them.
- Global materials use the existing persistent collection storage and backup flow.
- Product/category/price/NFC data is not rewritten by this patch.
- V3.1.61 reveal/NFC Stand/Premium Plus fixes remain untouched.

### Cache
- Shared site asset revision: `3.1.64-r1`.
- Catalog admin companion revision: `3.1.64-r1`.

### Apply
1. Close Product Manager completely.
2. Overlay this patch on V3.1.64.
3. Reopen Product Manager.
4. Open a product and select its materials / personalization state.
5. Save the product.
6. Click `Siteyi yeniden oluştur` if needed after bulk material changes.
7. Commit + push.
8. Ctrl + F5 on the live catalog.
