# BG Studio 3D V3.3.00 · BG Assistant Foundation

Baz: V3.2.05 STABLE

## Gelenler
- Tüm public sayfalara BG Assistant launcher
- Masaüstü, tablet, Android ve iOS uyumlu sohbet paneli
- Ürün Yönetim Merkezi'ndeki aktif ürünlerden build sırasında oluşturulan katalog bilgisi
- Ürün adı / kategori / açıklama üzerinden yerel ürün eşleştirme
- Güncel ürün fiyat metnini gösterebilme
- NFC + QR, özel üretim, prototip, kurumsal, teslimat ve mimarlık yönlendirmeleri
- Hızlı soru chipleri
- Teklif ve ilgili sayfalara doğrudan CTA
- Son soruyu WhatsApp mesajına aktaran handoff
- Escape ile kapatma, focus davranışı ve aria-live mesaj alanı
- Safe-area ve mobil ürün CTA uyumu

## Önemli mimari not
Bu Foundation sürümü harici bir LLM / OpenAI API çağrısı yapmaz.
Yanıtlar build sırasında site verilerinden oluşturulan katalog + tanımlı BG Studio hizmet bilgi tabanı üzerinden yerel olarak hazırlanır.

Bu sayede API anahtarı frontend'e açılmaz, ilk sürüm ek sunucu maliyeti oluşturmaz ve ürün verileri Product Manager ile birlikte güncel kalır. Sonraki V3.3.x sürümlerinde gerçek AI backend'i güvenli biçimde eklenebilir.
