# BG Studio 3D V3.3.01 · OpenAI Connector

Baz: V3.3.00

## Ne değişti
- BG Assistant artık önce `/api/bg-assistant` backend endpointine bağlanır.
- Backend OpenAI Responses API kullanır.
- Varsayılan model: `gpt-5.6-luna` (Cloudflare env ile değiştirilebilir).
- Sohbet geçmişinin son kısmı gönderilir.
- Product Manager’dan gelen ürün katalog verisi AI bağlamına eklenir.
- OpenAI veya Worker erişilemezse mevcut yerel bilgi motoruna otomatik fallback olur.
- `merhaba`, `selam` gibi basit konuşmalar fallback tarafında da doğal yanıt verir.
- İstek sırasında `Yanıt hazırlanıyor…` durumu gösterilir.
- API anahtarı hiçbir zaman browser JavaScript’ine yazılmaz.

## Cloudflare Worker kurulumu
1. OpenAI Platform’dan bir project API key oluştur.
2. `cloudflare/wrangler.toml.example` dosyasını `wrangler.toml` olarak kopyala.
3. Cloudflare hesabında `bgstudio.com.tr` zone’una Worker route yetkisi olduğundan emin ol.
4. Worker dizininde `npx wrangler secret put OPENAI_API_KEY` çalıştır ve anahtarı yapıştır.
5. `npx wrangler deploy` çalıştır.
6. Route: `3d.bgstudio.com.tr/api/bg-assistant*`.
7. Siteyi V3.3.01 ile rebuild/deploy et.

> OpenAI key sadece Worker secret olarak tutulmalı. Frontend’e veya GitHub repo’ya yazılmamalıdır.

## Model değiştirme
`wrangler.toml` içindeki `OPENAI_MODEL` değerini değiştir. Varsayılan `gpt-5.6-luna`.
