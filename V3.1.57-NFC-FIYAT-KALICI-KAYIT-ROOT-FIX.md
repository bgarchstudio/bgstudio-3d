# V3.1.57 · NFC fiyat kalıcı kayıt root fix

## Sorun
`NFC website bilgileri` ekranında fiyatlar kaydedilmiş görünmesine rağmen sayfa F5 ile yenilendiğinde eski fiyatlara dönebiliyordu. Önceki akış POST cevabındaki bellekteki yeni veriyi başarı olarak gösteriyor, fakat build sonrasında kalıcı depolamayı tekrar okuyup fiyatların gerçekten kaldığını doğrulamıyordu.

## Düzeltme
- NFC website fiyatları için `nfc_site_pricing` adlı ayrı kalıcı koleksiyon eklendi.
- Bu koleksiyon fiyatlar için ana kaynak kabul edilir.
- `site_settings.nfc_site` geriye uyumluluk ve public site çıktısı için aynı verinin aynası olarak tutulur.
- Fiyat kaydı önce ayrı kalıcı koleksiyona yazılır ve anında geri okunarak doğrulanır.
- Build artık varsa `nfc_site_pricing` verisini tercih eder.
- Build tamamlandıktan sonra sunucu fiyatları tekrar kalıcı depodan okur.
- Fiyatlar geri dönmüşse bir kez otomatik onarım + rebuild yapılır.
- Onarım sonrası değer yine doğrulanamazsa panel artık sahte başarı mesajı vermez.
- Tarayıcı da POST sonrasında ayrı GET isteğiyle F5 eşdeğeri doğrulama yapar.

## Veri güvenliği
Bu patch `data/*.json`, ürün kayıtları, referanslar veya medya dosyaları içermez. Mevcut verinin üzerine yazmaz. İlk açılışta mevcut `site_settings.nfc_site` fiyatları yeni kalıcı fiyat koleksiyonuna seed edilir.
