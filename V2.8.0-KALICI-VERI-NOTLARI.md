# BG Studio 3D v2.8.0 — Kalıcı Veri Kasası

Bu sürümde yönetim panelinin kaynak verisi GitHub repo klasöründen ayrıldı.

## Kalıcı konum
Windows'ta panel verileri artık `%LOCALAPPDATA%\BGStudio3D` altında tutulur:

- `bgstudio3d.db` — ürünler, fiyatlar, setler, renkler, stoklar, NFC kayıtları, kurumsal referanslar ve prototipler
- `media\` — panelden yüklenen ürün / poster / referans / logo / prototip görselleri
- `backups\` — veritabanı ve tam veri+medya yedekleri

CMD, `server.py`, HTML/CSS/JS veya bütün repo klasörü ileride değişse bile bu klasör silinmediği sürece panel verileri korunur.

## İlk geçiş
İlk v2.8.0 geçişinde TAM PAKETİ mevcut repo üzerine kopyalamadan önce `v2.8.0-ILK-GECIS-GUVENLI-PATCH.zip` kullanılmalıdır. Bu patch `data/` ve panelde yüklenen görselleri içermez; mevcut yerel değişiklikleri ezmez.

Patch'i repo üzerine kopyaladıktan sonra:

1. `KALICI-VERIYE-GECIS.cmd` çalıştırılır.
2. Mevcut repo ürünleri, renkleri, NFC/kurumsal/prototip kayıtları ve panel görselleri AppData kasasına aktarılır.
3. İlk tam güvenlik yedeği otomatik oluşturulur.
4. Sonrasında `URUN-YONETICI.cmd` normal şekilde kullanılır.

## Sonraki sürümler
İlk geçiş tamamlandıktan sonra yeni tam paket repo üzerine kopyalansa dahi `URUN-YONETICI.cmd` açılırken AppData'daki güncel veri repo çıktısına geri senkronlanır. Paket içindeki eski JSON veya görsel kopyaları kaynak veri olarak kabul edilmez.

## Ek araçlar
- `KALICI-VERI-KONTROL.cmd` — kasanın konumunu ve kayıt sayılarını gösterir.
- `KALICI-VERI-YEDEKLE.cmd` — tek tık tam veri + medya yedeği alır.
- Yönetim panelindeki `Yayın kontrolü` ekranındaki yedekler de artık AppData kasasında tutulur.
