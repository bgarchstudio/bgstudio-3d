# BG Studio 3D V3.3.14 · Release Candidate / Production Hardening

Baz: V3.3.13 Launch QA / Bug Hunt
Release: V3.3.14-RC1

## RC build gate
Product Manager build çıktısında artık iki yeni alan vardır:
- `release_candidate`
- `release_gate`

`release_candidate.ready = true` olduğunda shell + SEO + launch audit kritik kontrolleri temizdir.

Normal build hata vermeden rapor üretmeye devam eder. Production/CI için:

`BG_STUDIO_STRICT_RELEASE=1 python tools/product_manager/build.py`

kullanılırsa RC kritik hatalarda build durur.

## Standalone release checker
Yeni araç:

`python tools/product_manager/release_check.py --strict`

Product Manager build SONRASINDA tüm üretilmiş public HTML üzerinde şunları tarar:
- title / description / canonical / viewport / build meta
- kırık internal linkler
- eksik local image / JS / CSS assetleri
- blocking local scriptler
- target=_blank + noopener
- eski asset cache version
- mixed content
- duplicate id
- alt eksik img
- sitemap ↔ generated route tutarlılığı
- robots sitemap satırı
- nested 404 için root base
- production styles.min.css durumu
- aktif olmayan eski NFC servis-talebi metinleri

`--json` ile CI/otomasyon için makine okunur rapor alınabilir.
