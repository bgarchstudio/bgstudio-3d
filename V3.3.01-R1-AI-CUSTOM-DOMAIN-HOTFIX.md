# BG Studio 3D V3.3.01-R1

Baz: V3.3.01 OpenAI Connector

## AI Custom Domain Hotfix

Cloudflare Worker artık `ai.bgstudio.com.tr` custom domain altında çalışıyor. Ana `3d.bgstudio.com.tr` GitHub Pages origin'i ile Worker route'u çakışmasın diye frontend endpoint'i cross-origin Worker domainine taşındı.

### Değişiklikler
- BG Assistant API endpoint: `https://ai.bgstudio.com.tr/api/bg-assistant`
- Fallback endpoint de aynı custom domaini kullanır
- Cross-origin istekte `credentials: omit` kullanılır
- `ALLOWED_ORIGINS=https://3d.bgstudio.com.tr` Cloudflare ayarıyla uyumludur
- OpenAI API anahtarı yalnızca Cloudflare Secret olarak kalır

### Doğrulama
Tarayıcıdan `https://ai.bgstudio.com.tr/api/bg-assistant` açıldığında `Method not allowed` JSON cevabı görülmesi Worker'ın aktif olduğunu doğrular. Gerçek BG Assistant isteği POST ile yapılır.
