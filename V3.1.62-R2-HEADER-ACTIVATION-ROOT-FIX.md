# BG Studio 3D V3.1.62-R2

Baz: V3.1.62 (V3.1.61 üzerine kurulan PATCH 1)

Bu hotfix, V3.1.62 dosyaları diske kopyalandığı halde açık kalan Product Manager Python sürecinin eski `build.py` modülünü bellekte tutması ve public HTML header migrationının canlı dosyalara ulaşmaması riskini giderir.

## Düzeltmeler
- Her build çağrısında `build.py` diskten yeniden yüklenir.
- Product Manager açılışında public header ve asset shell otomatik senkronlanır.
- Public sayfalara `data-bg-nav="v3.1.62-r2"` doğrulama işareti yazılır.
- `navigation.js` ve CSS/JS query sürümü `3.1.62-r2` ile cache-bust edilir.
- Build sonunda bütün public headerlar doğrulanır; eski header kalırsa build başarılı görünmez, açık hata verir.
- Ürün detay sayfalarının generator şablonu da doğrudan canonical header üretir.
- V3.1.61 reveal, NFC Stand Şeması, Premium Plus, fiyat ve paket motorlarına dokunulmaz.

## Bir defalık uygulama
1. Product Manager'ı tamamen kapat.
2. Bu hotfix dosyalarını V3.1.62 repo üzerine kopyala.
3. Product Manager'ı yeniden aç.
4. Siteyi yeniden oluştur.
5. Yayınla / repo senkronunu tamamla.
6. Canlı sitede Ctrl + F5.
