# BG Studio 3D V3.3.12 · Performance & Launch Audit

Baz: V3.3.11 Mobile Final Polish

## Performans
- `styles.min.css` artık gerçek minified production CSS olarak build sırasında otomatik üretilir.
- `styles.css` okunabilir geliştirme kaynağı olarak korunur.
- Minifier string/calc güvenli, konservatif yapıdadır; yorumları ve gereksiz dış whitespace'i temizler.
- Public sayfalar zaten `styles.min.css` kullandığı için HTML yapısını değiştirmeden transfer boyutu düşer.

## CLS / görsel stabilitesi
- Build sırasında yerel PNG/JPG/WebP benzeri görsellerin gerçek piksel ölçüsü okunur.
- HTML img etiketinde width/height yoksa intrinsic ölçüler otomatik eklenir.
- Responsive CSS boyutları değişmez; tarayıcı görsel yüklenmeden önce doğru oranı ayırabilir.
- Remote, data URI ve SVG varlıkları güvenli biçimde atlanır.

## Mevcut optimizasyonlar korunur
- Hero preload / fetchpriority sistemi korunur.
- Hero dışındaki görseller lazy-load + async decoding kullanmaya devam eder.
- Google Fonts non-blocking yükleme stratejisi korunur.
- Scriptler defer düzeninde kalır.
- V3.3.11 visualViewport ve mobil düzenlemeleri korunur.

## Launch Audit
Product Manager build çıktısına yeni `launch_audit` raporu eklendi:
- blocking local script kontrolü
- alt eksik görsel kontrolü
- intrinsic dimension eksikleri
- mixed-content kontrolü
- duplicate id kontrolü
- CSS source/minified byte farkı

Audit raporları build'i durdurmaz; yayın öncesi görünür uyarı olarak çalışır.
